# 本地工具台

本地工具台为YD账号提供套餐余量、账单和已订业务查询，以及灵犀对话、卡券、权益和活动任务。同一个手机号可以在「账号管理」登录后供多个功能使用。

## 下载和启动

从 [GitHub Releases](https://github.com/pppyl/lingxi-workspace/releases/latest) 下载与你的设备匹配的客户端。发布页提供版本说明和 `SHA256SUMS.txt` 校验文件。

| 方式 | 系统要求 | 启动方法 |
| --- | --- | --- |
| Windows 单文件版 | Windows 10/11 x64 | 双击下载的 EXE 启动后台服务，从托盘选择「打开工具台」。 |
| Windows 文件夹版 | Windows 10/11 x64 | 完整解压下载的 ZIP，保留同目录的 `_internal`。运行 `LingxiWorkspace.exe` 后，从托盘选择「打开工具台」。 |
| Android 独立版 | Android 7.0+，ARM64 | 安装 ARM64 APK 后打开「本地工具台」。服务和任务在手机本机运行。 |

Windows 客户端和 Android 独立版都自带运行环境，下载后可直接使用，无需安装 Python 或 Node.js。

首次使用时，在「账号管理」添加YD手机号并完成短信验证，再进入对应功能选择账号。多个号码可以分别加入账号池。电脑端的账号列表位于各功能左侧，Windows 客户端可从托盘重新打开界面。

### 从源码运行

在 Windows 的项目根目录安装 Python 3.12 依赖并启动服务。

```powershell
python -m pip install -r requirements.txt
python -X utf8 app.py
```

也可以在安装依赖后运行 `start.ps1`。启动后访问 [本地首页](http://127.0.0.1:5500/)。

## 功能

| 页面 | 能做什么 |
| --- | --- |
| 信息查询 `/information` | 一次选择账号，查看套餐余量、月度账单和已订业务。余量卡片可展开明细。官方允许退订的业务可在核对影响后提交。 |
| 灵犀对话 `/lingxi`、定时发送 `/lingxi/tasks` | 按账号进行即时对话，预约单次或每周任务，查看执行记录和回复。 |
| 网龄 `/net-age` | 查看月月领权益、会员和 AI 权益、生日礼及惊喜礼。惊喜礼按有效账号每日检查，官方确认有次数时自动抽奖。 |
| 周三充值日 `/recharge/` | 查看周三领取、奖品、任务及连续打卡进度。邀请助力任务可获取官方链接和口令。 |
| 签到有礼 `/checkin`、微信渠道 `/checkin/wechat` | 统一选择当前账号，查看其签到、自动任务和「签到专属 AI 豆」，可核对余额和兑换话费券。批量签到、全账号自动设置使用独立入口。微信渠道使用独立手机号列表和短信登录。 |
| 星动日 `/star-day` | 查看每日签到和本月权益。符合资格的账号可手动领取、预约抢购或按官方条件赠送权益。 |
| 每月话费券 `/monthly-coupon` | 贵州YD活动。查看当月直接领取、任务进度和额外领取结果，支持每日自动检查。 |
| 我的卡券 `/coupons` | 查可用券、历史、折扣和使用条件。支持的券可兑换或用于生成待支付充值订单，付款由你在官方收银台确认。 |
| 我的权益 `/mobile-rights`、`/member-benefits` | 「权益领取」可查领本月权益、新青年瑞幸券及 AI 豆。「会员领取」可查看已开通会员的礼包、福袋和其他可领权益。 |
| 平台管理 `/platforms` | 设置功能开关、导航顺序、网络监听及访问密码，查看版本更新。 |

活动参与资格、券的适用条件及领取结果以YD返回的信息为准。短期活动到期后，入口和自动任务按活动状态停用。

### 信息查询

套餐余量、月度账单和已订业务分别加载，某一项查询失败时，其余结果仍可查看。切换账单月份只重查账单，查询范围是当前月及前 12 个月。账单的「实际应付」是对应月份的账单金额，「当前账户余额」是本次查询的实时余额。

套餐余量提供流量、通话和短彩信卡片，展开后可查看套餐明细、原始用量、有效期和适用范围。缺失数据用「—」表示，数值 `0` 保留。已订业务可按分类或名称搜索，也可筛选「仅看可退订」。提交退订前请核对生效时间、相关业务影响及官方验证要求。

### 卡券和充值订单

卡券页可搜索名称并按类型筛选，历史记录和有效期以官方数据为准。综合排序优先展示已生效的兑换券，再按充值折扣从低到高排列，未生效的券排在后面。

| 操作 | 结果与后续步骤 |
| --- | --- |
| 兑换话费或流量 | 核对卡券说明，有短信验证要求时先完成验证，再确认提交。显示「已受理」后，还可在官方记录中核对到账。 |
| 充值使用 | 页面根据官方规则展示优惠比例最高的档位，折扣相同时优先选择实付较低的方案。确认后生成待支付订单，可通过页面提供的官方付款链接或二维码付款。 |
| 继续付款 | 从「待支付订单」打开原订单。付款窗口为 30 分钟，重新登录或刷新支付链接不会延长窗口。未付款且未取消的订单可能占用原券 48 小时。 |
| 提示 `531022` | 在当前流程恢复登录，重新核对用券方案后再确认下单。 |

「待核实」表示官方结果还未确认。先核对原订单或卡券记录，确认结果后再决定下一步。订单移出待支付列表不代表退款或取消。

### 灵犀定时发送

在「定时发送」中选择一个或多个账号，填写内容和预约时间。可预约单次执行或每周同一天重复，也可以在列表中调整、停止或查看回复。

- 每轮默认发送 3 次，间隔 1 秒。可配置 1～20 次、间隔 0.2～3600 秒，同一轮从第一条到最后一条的计划时间最多相差 1 小时。
- 「发送设置」中的并发上限默认 256，可设为 1～1024。并发已满时，请求进入队列，实际发起时间可能晚于计划时间。执行记录可查看排队和实际发起时间。
- 停止任务会取消尚未发出的请求，正在接收的回复继续保存。执行中的任务应先停止，结束后可删除。已开始或结果不明的发送不会在重启时补发。

即时对话按账号维护独立会话，页面刷新会清空当前显示。定时发送的内容和回复随任务记录保存在本地。

### 权益领取与微信签到

- 「权益领取」打开页面或切换账号时加载权益。领取、添加关注和请求活动短信由对应按钮触发。新青年瑞幸兑换需要按官方要求验证，验证码与所选账号和兑换券绑定。领取 AI 豆后可查看官方确认的余额。
- 「会员领取」显示已开通会员对应的权益。福利有效期、是否可领及实际到账以官方结果为准。
- 微信渠道有独立的账号列表、登录凭据和签到记录。退出共享 App 账号不影响已登录的微信渠道账号。自动签到覆盖本渠道已登录的有效号码。

签到有礼中的「签到专属 AI 豆」是独立活动余额，与「我的权益」中的 AI 豆分别查询。已接入的查询、活动浏览、视频、云盘浏览、咪咕登录，以及百度地图、淘宝薅羊毛、菜鸟任务均通过 Python 在本机执行。合作方任务使用本人的有效登录，按账号加密保存；运行无需连接手机。百度地图、淘宝及菜鸟的登录失效后，可通过本地「合作方登录」入口更新。页面逐项显示官方进度和未接入原因，可执行当前账号或全部有效账号；话费券兑换需在本地页面确认。付款任务当前跳过。微信订阅及其余合作 App 的认证或任务回传仍未完整接通，不能仅凭打开链接标记完成。详细范围见 [签到专属 AI 豆协议](docs/protocols/CHECKIN_BEANS_PROTOCOL.md)和[逐项任务结果](docs/protocols/CHECKIN_BEANS_TASKS.md)。

## 自动任务怎么运行

以下时间均为北京时间。每日签到和检查任务到设定时间后开始，适用的任务会在晚启动或恢复账号时先核对官方进度，再补做当天尚未完成的项目。定时抢购按各自的场次窗口运行。

| 任务 | 默认时间 | 执行规则 |
| --- | --- | --- |
| 签到有礼 | 每日 08:00 | 覆盖有效共享账号。已签到的账号跳过，状态和最近结果可在页面查看。 |
| 签到秒杀 | 12:00，可配置到秒 | 自动识别每周或月末场次。默认每账号 40 次、间隔 50 毫秒，提前准备并共用一次校时。是否开放及领取结果以官方为准。 |
| 周三充值日领取 | 周三 07:55 准备，08:00 开始 | 有效账号自动加入，每个账号本场最多提交 20 次。晚启动或恢复登录时先核对当场进度，再使用剩余次数。地区开放时间以官方场次为准。可停止本周任务，下周自动恢复。 |
| 周三连续打卡 | 每日 00:01，可修改 | 按天核对官方任务。第 3 天可获取邀请链接或口令，由好友助力。第 5 天需要实际充值。达成连续 7 天条件后，按官方状态领取 8 折券。 |
| 每月话费券 | 每日 08:05，可修改 | 贵州YD活动。直接领券和额外领券各按月核对。额外领券需要完成账单、签到活动、网龄专区的浏览任务，并累计打卡 3 天。 |
| 星动日 | 默认 00:01 签到、09:30 准备活动凭据。预约权益在 10:00 开始 | 活动凭据准备时间可设为 08:00～10:00。预约按账号核对本月领取状态，当月成功后跳过，下月恢复。当日频控或资格、认证拒绝按页面状态处理。 |
| 网龄惊喜礼 | 每日检查 | 覆盖有效共享账号，官方确认仍有次数时参与，结果待核实时查询记录。 |

星动日可以手动领取权益，也可在官方支持时赠送。手动领取和赠送都使用来源账号当月权益机会，成功后计入当月状态。预约任务可配置抢购轮次。当日错过预约窗口时，后续按任务规则继续。

星动日活动凭据最长复用 2 小时。后台只在设定的准备时间获取活动凭据，错过准备时间后等下一次计划，已有效登录的活动会话可以继续使用。官方提示当天请求频繁时，后台停止当天重试，按页面提示处理。

定时任务需要运行服务的设备在线。Windows 关闭浏览器标签页后，托盘客户端仍可执行任务。电脑休眠、手机强制停止应用或系统限制后台运行时，任务可能错过执行窗口。

## 账号、数据与更新

账号与任务保存在运行设备上。Windows 凭据使用当前用户的系统加密保护，Android 使用应用私有目录和系统密钥保护。备份时请保留完整目录，迁移到其他设备后可能需要重新登录。

| 运行方式 | 数据位置 |
| --- | --- |
| Windows 客户端及 Windows 源码服务 | 共用 `%LOCALAPPDATA%\LingxiWorkspace\data`。主库为 `accounts.sqlite3`，周三充值日辅助文件位于 `recharge/`，迁移前的原库和凭据备份也保存在此目录内。 |
| Android 客户端 | 应用私有目录。同签名覆盖安装可保留数据，卸载会清除数据。 |

共享账号、合作方登录态、活动会话、任务配置与记录统一存放在上述数据目录，项目内不再保存账号数据。默认首次启动会核对并迁移旧目录：原数据库归档到 `migration-backups/`，不覆盖已有的新库；发现两份非空旧账号库时停止迁移并提示选择来源，不自动混合账号。开发时可用 `LINGXI_DATA_DIR` 指定项目外的独立目录；指定后不自动导入默认目录的数据。

同一账号的有效身份会在相应功能中复用。共享 App 身份需要重新验证时，进入「账号管理」恢复登录；百度地图、淘宝及菜鸟使用的合作方身份，在「签到有礼 → 签到专属 AI 豆 → 合作方登录」中管理：

- **检查并更新**：使用已保存会话查询官方身份，并保存官方返回的 Cookie 更新；不重新扫码或自动发短信。
- **扫码更新**：旧会话确实失效时，获取官方二维码，在对应官方 App 扫码确认。Python 完成登录交换、核对原绑定身份并加密保存；此后执行任务无需手机连接。
- **手动更新**：导入本人 Cookie、Cookie JSON 或 Netscape 文件，验证通过才替换旧会话。首次配置百度地图还需本人的 `phone_info`（`cuid`、`sv`），后续更新复用。

更新入口沿用页面当前共享账号。导入失败、账号不匹配或网络异常不会覆盖原登录态；有任务、兑换或待核实提交时暂缓替换。官方要求额外验证时明确提示，不标记更新成功。扫码生成和等待状态已实测，完整的扫码确认及官方身份回查仍需本人完成一次扫码验证。

- 每个手机号在共享账号池中保留一个账号。重新登录会保留账号备注和任务绑定。退出账号会移除该号码的登录凭据，并停止对应的后续任务。
- App 主会话可使用已有续期凭据在后台维护。活动和卡券的有效会话按各自的认证规则继续使用。官方明确要求短信验证时，由你在对应页面完成验证。
- 已建立的兑换和支付流程绑定对应会话。出现认证拒绝或结果不明确时按页面提示处理，避免再次提交同一笔操作。短信验证码不会保存在账号数据库中。

程序启动后会检查 GitHub 正式版本，之后约每 6 小时检查一次。也可在「平台管理 → 版本更新」手动检查并查看说明。Windows 更新前从托盘退出旧客户端，Android 下载新版后使用同签名 APK 覆盖安装。更新源码时保留数据目录。

「平台管理」还可以关闭单个功能或调整导航顺序。关闭功能会暂停其业务入口和后续自动任务，已有配置和记录可在重新开启后继续使用。

短期和长期活动支持独立的 ZIP 活动包。可在本机「平台管理 → 功能开关」导入、升级或导出，导入后重启工具台生效。目录结构和 Python 接口见[活动包开发规范](docs/ACTIVITY_PLUGIN.md)。

## 从其他设备访问

电脑服务默认端口为 `5500`。本机用 `127.0.0.1` 或 `::1` 访问，其他设备使用该电脑的局域网地址。IPv6 地址写在方括号内，例如 `http://[IPv6地址]:5500/`。

1. 在电脑的「平台管理 → 访问密码」设置至少 8 位的密码，再从其他设备打开电脑的访问地址。局域网内的设备共用这台电脑的账号与任务。
2. 在「网络监听」选择对外开放的 IPv4、IPv6 或指定网卡。指定网卡的地址变化后会跟随更新。本机回环入口继续可用。
3. 如果局域网连接被 Windows 防火墙挡住，管理员可运行文件夹版附带的 `allow-lan.ps1` 放行局域网的 TCP 5500。

只允许本机访问时，启动前设置 `LINGXI_HOST=127.0.0.1`。可用 `LINGXI_PORT` 修改端口。通过域名或反向代理访问时仍使用远程访问验证。

远程访问登录最长保留 7 天。修改访问密码后，其他设备需要重新登录。连续输错密码时，等待时间会从 5 秒逐步增加，上限为 5 分钟，多个设备共用此等待状态。

Android 独立版的本地服务仅供手机应用使用。Windows 和 Android 的网络、升级及构建细节见各自说明。

| `GET /api/logins` | 查询共享账号状态，凭据留在服务端。 |
| `POST /api/logins/sms`、`POST /api/logins/login` | 请求短信验证码及登录。已有账号可通过对应的 `/api/logins/relogin/sms` 和 `/api/logins/relogin` 恢复。 |
| `POST /api/chat` | 发送灵犀消息，响应以 SSE 流返回。 |
| `GET /api/lingxi/tasks`、`GET /api/lingxi/tasks/<task_id>` | 取任务列表或单条任务的详细记录。 |
| `POST /api/lingxi/tasks/save` | 新建或编辑任务。新建使用 `login_ids`、`content`、`run_at`，可附带 `repeat_count`、`interval`、`weekly`。 |
| `POST /api/lingxi/tasks/adjust`、`/api/lingxi/tasks/stop-batch`、`/api/lingxi/tasks/delete-batch` | 用 `ids` 选择待操作的任务。批量调整还需传入 `changes`，只更新其中明确选择的字段。 |
| `GET /api/lingxi/settings`、`POST /api/lingxi/settings` | 读取运行中、排队及并发设置，或修改并发上限。 |

</details>

安装 Python 依赖和 Node.js 后，可运行回归测试。

```powershell
python -X utf8 -m unittest discover -s tests
npm ci
npm test
```

不同版本的实测范围见发行说明。使用模拟响应的回归测试可验证页面和流程处理，线上活动结果仍以运营商实际回执为准。
