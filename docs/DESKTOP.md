# 本地工具台 · Windows 客户端 v2.2.5

1. 推荐直接双击单文件版 `LingxiWorkspace-2.2.5-Windows-x64.exe`，无需安装。也可将 ZIP 完整解压到一个文件夹，双击其中的 `LingxiWorkspace.exe`。
2. 界面使用系统默认浏览器，不内置浏览器，不需要安装 Python、Node.js 或连接手机。首次使用在「账号管理」中登录自己的手机号。周三活动及会员权益的设备参数由 Python 调度内嵌 V8 在本地计算。
3. 支持灵犀即时对话、多账号定时发送、星动日签到与权益领取／赠送、周三充值日、签到有礼与月末秒杀、每月话费券、我的卡券查询和使用，以及可到期停用和永久移除的短期活动。
4. 客户端启动和重启时在任务栏通知区域运行。双击托盘图标、选择「打开工具台」，或用 `--open` 参数运行 EXE，即可在默认浏览器打开界面。关闭浏览器后定时任务继续执行。右键托盘图标选择「退出客户端」可停止服务。
5. 定时任务需要电脑保持开机、联网且不休眠，客户端保持运行。
6. 每日签到默认覆盖所有有效共享账号，新登录及恢复登录的账号自动加入，晚启动核对后补做未完成任务。签到时间和月末秒杀参数可在对应页面调整；已完成或结果不确定的提交不自动重放。周三充值日自动在周三 07:55 准备、08:00 开始领取。
7. 启动时及每 6 小时检查 GitHub 正式版本，发现新版后显示提示与对应下载入口；可在「平台管理 → 版本更新」手动检查、查看更新说明。更新时先下载新版，再从托盘退出旧客户端并运行新版，账号和任务保留。

适用 Windows 10/11 64 位。客户端默认同时监听 IPv4／IPv6，默认 5500 端口，其他设备可打开 `http://电脑IPv4地址:5500/`、`http://[电脑IPv6地址]:5500/` 或指向此服务的合法域名，共用此电脑的账号和任务。左侧“本地服务”显示访问地址；「平台管理 → 网络监听」可分别开启或关闭两种对外监听，设置保存后实时生效，已选网卡的 IP 变化后自动更新监听，本机入口始终保留。本机回环访问无需密码，远程首次进入须先设置访问密码；之后需要密码登录，可在「平台管理」修改。错误等待按 5、10、30、60、120、180、300 秒递增，上限 5 分钟；刷新或重启不能绕过。修改密码使其他设备的旧登录失效。若系统拦截入站连接，可放行该客户端；文件夹版附带 `allow-lan.ps1`，可用管理员 PowerShell 运行，仅放行局域网 TCP 5500。端口被其他程序占用时自动使用空闲端口，以程序界面显示的实际端口为准。设置环境变量 `LINGXI_HOST=127.0.0.1` 可恢复仅本机监听；指定该变量时页面显示监听由运行环境控制。

账号相关数据统一保存在 `%LOCALAPPDATA%\LingxiWorkspace\data`，Windows 客户端与源码运行共用此目录。共享账号、合作方登录态、活动会话、任务配置与记录均在其中；主库为 `accounts.sqlite3`，周三充值日辅助文件位于 `recharge/`。托盘菜单可直接打开数据目录。更新时退出旧客户端，解压新版本运行，原数据继续使用。发布包不含开发者的账号、Cookie 或任务记录。

默认首次启动会核对并迁移旧版数据，迁移前原库归档在新目录的 `migration-backups/` 内。已有新库不会被旧库覆盖；两份旧库都含账号时会停止并提示，不自动合并。备份时保留完整数据目录。使用 `--data-dir` 或 `LINGXI_DATA_DIR` 指定独立目录时，路径必须在项目外，且不会自动导入默认目录的数据。

百度地图、淘宝及菜鸟的合作方登录更新入口位于「签到有礼 → 签到专属 AI 豆 → 合作方登录」。可检查现有会话、扫码更新，或验证后导入本人登录资料；沿用当前共享账号并核对原绑定身份。更新后凭据加密保存，任务运行无需 USB、root 或手机联动。首次配置百度地图仍需本人设备资料，官方额外验证不会被绕过。

从 v1.0.0 更新时，先从托盘退出旧版，再运行新版，保留原账号和定时任务。

登录凭据使用 Windows 当前用户加密，其他电脑首次使用须登录自己的账号。账号是否需要短信验证，以运营商的实际校验结果为准。

单文件版 EXE 可以直接发给其他人。ZIP 中的文件夹版则须保留 `_internal` 文件夹，不能单独取出其 EXE。

如启动失败，弹窗会显示具体异常和完整日志路径；数据目录准备与旧版迁移失败同样会记录在 `desktop.log` 中。请提供最后一次 `Desktop startup or shutdown failed` 及其下方的 Traceback，以区分文件缺失、数据目录、监听端口等错误。ZIP 文件夹版须完整解压并保留 `_internal`，不能只复制其中的 EXE。首次解压包未携带数字签名。

Windows ZIP 文件夹版附带 `diagnose_windows_startup.ps1`。出现启动问题时，可在解压目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\diagnose_windows_startup.ps1`。用单文件版时，可把脚本复制到 EXE 同目录。脚本核对程序哈希、环境配置、旧版和新版数据路径及已有启动错误，报告写入临时目录。如果旧版的账号库仍在 `LingxiWorkspace` 根目录，请保留该目录供新版迁移。

系统代理／局域网代理兼容修复：客户端内部的本机启动检查和托盘控制请求直接连接 `127.0.0.1`，不经过系统或环境代理；对外业务请求保留原有网络设置。旧包若仅在开启代理时启动失败，可先在代理的排除列表加入 `127.0.0.1`、`localhost`，再更新到包含此修复的客户端。

启动自检使用独立的本机客户端信息接口，不渲染业务首页；日志记录实际启动版本、程序路径和数据目录，超时时保留最后一次连接异常或 HTTP 状态。启动检查失败会关闭本次监听并清理运行记录，避免失败进程继续占用端口或阻挡重启。

源代码与发布：https://github.com/pppyl/lingxi-workspace

APP 通话组队首次使用时，确认通话手机已有中国移动默认电话授权后，本机自动准备并加密保存设备参数；无需从其他电脑迁移配置。队伍满员且全员任务完成后，后台自动逐账号领取组队奖励并核对官方结果。

通话已经完成但授权待确认时，可单独补齐已有授权，无需重拨；iOS 队员不要求默认电话授权。组队奖励按官方全队达标和个人可领取状态核对，任务明细延迟更新不再额外阻止领取。

共享账号入池只依赖 APP 短信登录成功，灵犀在使用时独立连接；灵犀异常不会要求重复短信登录，也不会清空有效 APP 身份。组队领奖请求完成后会解除执行中状态，失败时可查看返回码与重试限制原因，未知领奖结果继续只读核对。
