# v2.2.6 · Android 与 Windows

- APP 通话组队模块升级至 1.1.0：已入队账号的通话任务由后台按官方协议提交并回查，页面提供立即执行及失败后主动重试入口。移除目标号码、拨号跳转和人工接通确认。
- 通话任务提交前保存待核实状态；结果不确定时跨重启只回查，官方明确拒绝后停止自动重试。组队奖励继续按官方达标状态领取并核对。
- 将签到、卡券、每月话费券、星动日和灵犀定时任务路由归入各功能目录，整理活动包管理、Windows 启动实现、构建资源及开发文档。
- Android APK 和 Windows 客户端同步升至 2.2.6；Android 沿用原应用标识与签名，支持覆盖安装。

通话组队本次调整的自动回归使用合成账号和模拟官方响应，未据此宣称真实账号任务或奖励已经完成。真实业务完成状态以官方回查为准。

## 验证

- 本地 Python 主测试 1665 项（跳过 3 项）、活动模块测试 197 项、前端测试 287 项，执行结果无失败。测试目录仅留在本地。
- Windows EXE 与 ZIP 均以隔离数据目录静默启动，核对 71 个页面和只读路由、75 个静态资源、托盘服务退出及旧活动配置保留；启动与验证未打开浏览器。无账号的查询接口按预期返回选取账号或登录提示。
- Windows 两种包各核对 97 个编译模块、148 个资源文件；APK 核对 137 个 Python 编译模块、116 个资源文件，均与回归所用源码和资源一致。
- APK 版本为 2.2.6 / 2206，ARM64，签名验证通过且与 v2.2.5 相同；三个客户端文件均核对 SHA-256。
- Android 本次未执行设备安装后的完整业务实测。短信、支付、兑换、领奖等真实账号操作的实际结果，仍需对应官方接口确认；现有未接通的认证或功能不会因本次打包标记为已完成。
